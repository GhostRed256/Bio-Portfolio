## 👋 Welcome
Welcome to my digital garden. This portfolio is a blend of my passions: creative coding, photography, and interactive web experiences. It's built to be dynamic, responding to the real world around you.

## ✨ Key Features

This isn't just a static site. I've engineered it to feel alive:

*   **Weather-Responsive Themes**: The entire UI adapts to your local weather. Raining outside? It rains on my site. Night time? The theme goes dark and moody.
*   **Interactive Arcade**: Hidden mini-games like Minesweeper and Tetris built directly into the footer.
*   **Immersive Effects**: 
    *   **Bubble Text**: Interactive typography that responds to your cursor.
    *   **3D Tilt Cards**: Project showcases that react to mouse movement with realistic depth and shine.
    *   **Seasonal Celebrations**: Automatic festive transformations for holidays like Diwali, Halloween, and Christmas.
*   **Art Gallery**: A curated space for my photography and artwork.

## 🛠️ Built With

The core technology stack chosen for performance and developer experience:

### Core
*   **[React 19](https://react.dev/)**: For building a component-based, interactive UI.
*   **[Next.js 16](https://nextjs.org/)**: Utilizing the App Router for server-side rendering and optimal performance.
*   **[TypeScript](https://www.typescriptlang.org/)**: For type-safe, maintainable code.

### Styling & Animation
*   **[Tailwind CSS](https://tailwindcss.com/)**: For rapid, utility-first styling and a completely custom design system without UI libraries.
*   **[Framer Motion](https://www.framer.com/motion/)**: Powering the smooth, complex animations and page transitions.

### Data & APIs
*   **Open-Meteo API**: Providing real-time weather data without API keys.

## 🚀 Getting Started

If you'd like to run this locally:

```bash
# Clone the repo
git clone https://github.com/GhostRed256/Bio-Portfolio.git

# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to check it out.
