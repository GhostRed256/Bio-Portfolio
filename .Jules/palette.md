## 2024-05-24 - Missing ARIA Labels on Custom Interactive Elements
**Learning:** While standard interactive elements like buttons inside forms often get labels, custom interactive UI widgets—like theme dials, seasonal mode toggles, and carousel switchers built with icon-only buttons—frequently lack ARIA labels. Screen reader users can get stuck interacting with unlabeled buttons like `<ChevronLeft />`, `<Moon />`, or `<RotateCcw />` without knowing their purpose. State indicators (e.g., expanded/collapsed, currently selected dot, checked switch) are also vital.
**Action:** When creating custom theme pickers or interactive widgets, explicitly add `aria-label` to all icon-only buttons. Utilize `aria-expanded` for toggled menus, `aria-current` for the active item in lists/dots, and `role="switch"` alongside `aria-checked` for binary toggle behaviors to ensure full keyboard and screen reader accessibility.
